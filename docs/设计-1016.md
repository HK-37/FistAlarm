## 目标

Windows 桌面闹钟：到设定时间自动触发提醒，提醒方式是**桌面凭空出现一个拳头，一拳把画面击碎**。带管理界面（增删改多个闹钟）。

## 核心实现技巧

**"击碎画面"不需要真透明窗口。** 触发时先把当前桌面截一张图，用无边框全屏置顶窗口显示这张截图，然后在截图上播放"拳头砸入 + 画面碎裂成玻璃渣掉落"的动画，播完回到正常。用户看到的是"真屏幕被打碎了"，实现上只是一段全屏动画，难度大幅降低。

## 总体架构

一个 Python 工程，打包成**一个 exe**，靠启动参数区分两种模式：

| 启动方式 | 模式 | 干什么 |
|---|---|---|
| 不带参数 | 托盘常驻 | pystray 挂托盘图标，后台线程每秒对表；托盘菜单：闹钟管理 / 试播一次 / 退出 |
| `--strike "提醒文字"` | 动画播放 | 播碎屏动画 + 显示提醒，用户点关闭后退出 |

托盘端到点就用 `--strike` 拉起自己的一个子进程。这也天然支持"不开托盘、直接用 Windows 任务计划程序触发"。

## 四个组件

### 1. 调度核心（纯 Python，无 UI）

- 维护闹钟列表：时间、重复规则（单次 / 每天 / 工作日 / 自选星期）、备注文字、启用开关。
- **用对表而不是 sleep 计时**——每秒比对墙上时钟。这样电脑睡眠唤醒后不会因为计时器暂停而漏掉。
- 数据存 `%APPDATA%\FistAlarm\alarms.json`。

### 2. 管理界面

- pywebview 开小窗口，加载内置 HTML 页（表格 + 增删改表单）。
- JS 通过 pywebview bridge 调 Python 读写 `alarms.json`。
- 带"开机自启"开关（写注册表 Run 键）。

### 3. 动画播放器

触发序列：

1. **先截主屏**（mss 库）——注意顺序，必须在开窗口之前截，否则截到的是自己的窗口。
2. 开全屏无边框置顶的 pywebview 窗口。
3. Canvas 动画：拳头从屏幕外砸入 → 冲击波 + 裂纹蔓延 → 截图按 Voronoi 多边形碎成玻璃渣、带旋转和重力掉落 → 黑底浮现提醒文字。
4. 两个按钮：**关闭** / **贪睡 5 分钟**。
5. 配打击 + 玻璃碎音效（HTML audio，资源内嵌）。

### 4. 贪睡回传

播放器子进程用**退出码**表达结果：`0` = 关闭，`2` = 贪睡。托盘端读到 2 就把该闹钟临时加一个 5 分钟后的单次触发。

## 关键技术点

- **截图失败**（全屏独占程序、权限问题）则降级为纯黑背景，照常播动画。
- **多显示器** v1 只砸主屏（简化，碎的就是主屏画面）。
- **单实例锁**防止托盘双开。
- **WebView2 缺失**时提示安装（Win11 自带，基本不会碰到）。
- **打包**：PyInstaller 单 exe，HTML/JS/音效全打进资源。依赖只有 pywebview、pystray、mss、Pillow。体积预计 30~50MB。

## 测试策略

- 调度逻辑（下次触发时间计算、重复规则、贪睡叠加）走 pytest 单测——这是核心逻辑，必须测。
- 动画是视觉产物，用 `--strike` 手动命令人工验收。

## 实现顺序（建议）
